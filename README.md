- [SecOps Architecture](SECOPS-ARCHITECTURE.md) - Security hardening, routines, and procedures

## Security Reports Disclaimer

Security reports in this repository are published on a **delayed basis**. Publication of vulnerabilities and mitigation strategies does not confirm or deny whether our infrastructure was affected or whether patches have been applied.

## Note

This repo contains only public, non-sensitive information about our operational practices. No secrets, credentials, or private infrastructure details are included.
